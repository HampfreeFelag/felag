## 🚀 Быстрый старт

### Установка зависимостей:

```bash
npm install
```

### Запуск dev-сервера:

```bash
npm run dev
```

Откройте <http://localhost:4321> в браузере.

### Сборка для продакшена:

```bash
npm run build
```

### Превью продакшен-сборки:

```bash
npm run preview
```

## 🎨 Дизайн-система

### Nordic Layered Vector

- **Философия:** Скандинавский минимализм, слоистая векторная графика, руническая эстетика
- **Шрифты:** Cormorant Garamond (заголовки), Inter (текст), JetBrains Mono (код)
- **Палитра:** Deep Blue `#3A5F7F`, Amber `#D49B3B`, Moss Green `#6B7B5E`

**Цвета:**
- **Фон:** `#F5F0EB` — тёплый бежевый, как скандинавская бумага
- **Текст:** `#2C3E4A` — тёмный серо-синий
- **Акцент:** `#D49B3B` — янтарь (руна Феху)
- **Вторичный:** `#3A5F7F` — глубокий синий (щит)
- **Успех:** `#6B7B5E` — мох (прибыль)
- **Ошибки:** `#B85450` — приглушённый красный

**Концепция:** «Без магии. Только ремесло и честный курс.» Судовой журнал варяжского торгового товарищества.

## 📝 Контент

Статьи пишутся в Markdown формате в папке `src/content/blog-[lang]/[slug]/`

**Структура статьи:**
```markdown
---
title: "Заголовок"  # До 100 символов, H1
description: "Описание (150-160 символов для SEO)"
pubDate: '2026-01-15'  # Формат: YYYY-MM-DD
category: 'route'  # Одна из 7 категорий (см. таблицу выше)
draft: true  # true = скрыта, false = видна
---

# Заголовок статьи

Контент статьи...
```

## 🛠️ Технологии

- **Astro 5.x** — статический генератор сайтов
- **TypeScript** — типизация
- **CSS** — единый global.css с дизайн-токенами (nordic-tokens.scss)
- **Markdown/MDX** — контент блога
- **GA4** — Google Analytics 4 (отслеживание кликов, UTM-метки)
- **GitHub Actions** — автоматический деплой на GitHub Pages

## 🔒 Безопасность

**⚠️ ВАЖНО:** В публичный репозиторий коммитятся только файлы, необходимые для функционирования блога.

- Планы, стратегии и внутренняя документация хранятся в [приватном репозитории](https://github.com/HampfreeFelag/hampfreeblog-private)
- API ключи и секреты не должны попадать в репозиторий
- **Коммиты:** сообщения — на английском. `git config user.email "HampfreeFelag@users.noreply.github.com"`

## 📍 Деплой

Блог автоматически деплоится на GitHub Pages через GitHub Actions при пуше в ветку `main`.

### OG изображения

OG изображения автоматически генерируются при сборке:
- **Генерация:** `scripts/generate-og-images.mjs`
- **Хранение:** `dist/og/` (не коммитится, генерируется при сборке)
