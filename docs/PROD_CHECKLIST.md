# Чеклист перед продом и проверка публичного репо

Первый приоритет — корректность и безопасность того, что попадает в **публичный** репозиторий.

## 1. Контент и переводы

- [ ] **Заглушки:** В `src/content` нет статей с текстом «Content will be translated here» (проверка: `grep -r "Content will be translated here" src/content` → пусто).
- [ ] **Draft:** Статьи с `draft: true` не показываются на сайте — это ожидаемо, пока не снят флаг.
- [ ] **Переводы:** Для каждой статьи в RU есть соответствие в EN (одинаковый slug). При добавлении новой статьи — сразу RU + EN.
- [ ] **Эмодзи:** В статьях не больше 5-7 эмодзи (💡⚠️✅❌📊🎯).

## 2. Перелинковка

- [ ] **Скрипт:** `node scripts/check-internal-links.mjs` → «Internal library links OK».
- [ ] **Язык ссылок:** В статьях `blog-en/` только `/en/library/...`, в `blog-ru/` только `/ru/library/...`.

## 3. Категории и баннеры

- [ ] **Категории:** Во frontmatter везде одна из допустимых: `route`, `forge`, `helm`, `treasury`, `compass`, `logbook`, `crew`.
- [ ] **Баннеры:** Если используется `bannerImage`/`heroImage` — пути к картинкам корректны, файлы лежат в `assets/` статьи.

## 4. Безопасность (публичный репо — первый приоритет)

- [ ] **Секреты:** В коммитируемых файлах нет токенов, паролей, API-ключей. Pre-commit проверяет паттерны.
- [ ] **Пути к внутренним репо:** В отслеживаемых файлах нет путей к приватному репозиторию.
- [ ] **Документы только в private:** Планы, процедуры, аудиты не попадают в `git add`.

## 5. После пуша

- [ ] **Actions:** В [GitHub Actions](https://github.com/HampfreeFelag/felag/actions) workflow «Deploy to GitHub Pages» завершился успешно.
- [ ] **Прод:** Открыть главную, библиотеку и 2–3 статьи (RU/EN), проверить отображение и ссылки.

## 6. Соответствие законодательству РФ (38-ФЗ, 382-ФЗ) — БЛОКЕР ПУБЛИКАЦИИ

Юридический регламент полностью: `HampfreeBlog-Private/docs/03-guides/content/CONTENT_WRITING_GUIDE.md` §15–17 и `REFERRAL_LINKS_GUIDE.md` v2.

- [ ] **Ни одной реф-ссылки на криптобиржи** (bybit.com, bitget.com, bingx*, binance, okx, veles.finance, finbazar) — 382-ФЗ запрещает рекламу крипты и приём криптоплатежей. Упоминания/скрины в тексте — допустимы, ссылки — нет. Автоматизировано проверкой 7 в pre-commit.
- [ ] **Ни одного публичного крипто-кошелька** (`0x…`, BTC/LTC) на страницах сайта — запрет распространения информации о приёме крипты в оплату.
- [ ] **Каждая партнёрская ссылка (VPS/брокеры/донаты)**: плашка «Реклама» + данные рекламодателя (ИНН) + erid (38-ФЗ). Без erid баннер не публикуется (скрыт в компоненте).
- [ ] **Реклама только на легальных носителях**: блог, MAX, VK. **В Telegram реклама запрещена** (ограничение доступа РКН с 10.02.2026, разъяснение ФАС) — в TG только информирование о своих материалах.
- [ ] **Дисклеймер ИИР** присутствует на каждой статье (авто через Disclaimer.astro).
- [ ] **Отчётность в ОРД** — до 10-го числа следующего месяца за показы/переходы (календарь своего ОРД проверить).
