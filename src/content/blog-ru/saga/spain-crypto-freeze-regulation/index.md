## Введение

Испанское правительство рассматривает законопроект, наделяющий финансовый регулятор CNMV полномочия замораживать криптовалютные счета без судебного решения. Это один из самых жёстких национальных подходов к крипто-регуляции в Европе. Разбираем текст законопроекта и его последствия.

## Что предлагает законопроект

1. **CNMV получает право заморозки.** Регулятор может заблокировать счета крипто-компаний при подозрении на отмывание денег или финансирование терроризма.
2. **Без судебного ордера.** Решение принимается административно, обжалование — в течение 48 часов.
3. **Распространяется на всех.** Не только на испанские платформы, но и на иностранные, предоставляющие услуги резидентам Испании.

## Контекст: MiCA уже в силе

Европейский регламент MiCA (Markets in Crypto-Assets) вступил в силу в 2024 году и устанавливает единые правила для всех стран ЕС:
- Лицензирование крипто-платформ
- Требования к резервам стейблкоинов
- Обязательная раскрытие информации

Испанский законопроект выходит за рамки MiCA, добавляя административные санкции без судебного контроля.

## Сравнение с другими юрисдикциями

| Страна | Заморозка счетов | Без суда | Аналогичный подход |
|--------|-----------------|----------|-------------------|
| Испания | Да | Да | Нет |
| Франция | Да | Нет (суд) | Нет |
| Германия | Да | Нет (суд) | Нет |
| США | Да | Нет (суд/SEC) | Частично |
| Китай | Полный запрет | Да | Нет |

Испания — первая в ЕС, принимающая подход «заморозка без суда» для крипто-активов.

## Что это значит для трейдеров

1. **Риски для пользователей.** Счета могут быть заморожены по административному решению — без возможности оперативно оспорить.
2. **Комплаенс-давление.** Платформы, работающие в Испании, могут ограничить доступ для резидентов, чтобы снизить регуляторные риски.
3. **Прецедент для ЕС.** Если испанский подход будет одобрен, другие страны ЕС могут последовать примеру.

## Итог

Испанский законопроект — один из самых жёстких национальных подходов к крипто-регуляции в Европе. Заморозка счетов без судебного решения расширяет административные полномочия CNMV, но создаёт риски для пользователей. Прецедент может повлиять на регуляторную траекторию всей ЕС.

## FAQ

**Заморозка счетов — это конфискация?**
Нет. Заморозка — временная мера до расследования. Конфискация требует судебного решения.

**Как обжаловать заморозку?**
Законопроект предусматривает обжалование в течение 48 часов через административный суд.

**Затронет ли это децентрализованные платформы?**
Вероятно нет. DEX не имеют юрисдикции и централизованных счетов для заморозки.
