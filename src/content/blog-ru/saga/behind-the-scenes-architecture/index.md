## Введение: цель и архитектура

Проект FÉLAG — это одновременно личная база знаний по построению торговых систем и открытая площадка для документирования инженерного процесса. Ресурс создан для фиксации реального опыта: от настройки CI/CD до адаптивной верстки и интеграции аналитики.

Любые конструктивные замечания по коду, вёрстке или тексту приветствуются. Контакты — на странице ["О проекте"](/ru/about/).

## За кулисами: инженерные улучшения

Архитектура проекта прошла несколько итераций оптимизации. Ключевые изменения:

- **Непрерывная интеграция:** внедрен скрипт `npm run verify`, блокирующий коммиты при ошибках в JSON-LD, NUL-байтах или битых ссылках.
- **UX:** View Transitions API для плавной смены языка, сохранение позиции скролла при навигации, CSS-анимация переключения тем.
- **Адаптивная верстка:** каталог статей на CSS Grid с липким сайдбаром на десктопе и drawer-меню на мобильных.
- **Локализация:** аудит RU/EN версий, устранение расхождений в мета-тегах, паритет ключей переводов.

Детальная архитектура дистрибуции контента описана в отдельной публикации: ["Архитектура информационной гавани"](/ru/saga/information-harbor-architecture/).

## Масштаб работ за последние 4 дня

За период с 31 октября по 4 ноября команда проекта выполнила более 30 задач по выстраиванию архитектуры блога:

**Инфраструктура и автоматизация:**
- Внедрён скрипт автоматической валидации (`npm run verify`), который блокирует сборку при ошибках в JSON-LD, битых ссылках или дубликатах контента
- Настроена непрерывная интеграция с автоматическим деплоем на GitHub Pages
- Реализована система пре-коммит хуков с 7 проверками качества

**Пользовательский опыт (UX):**
- Обеспечен бесшовный UX: внедрена логика сохранения позиции скролла при кросс-URL навигации и смене языка
- Добавлены плавные переходы между темами (View Transitions API)
- Выстроена адаптивная Grid-система: от мобильного drawer-меню до десктопного sticky-сайдбара

**Качество контента:**
- Достигнут строгий паритет локализации: полностью синхронизированы мета-теги, заголовки и ключи переводов для RU и EN версий
- Унифицировано поведение всех ссылок: исправлен CSS-каскад, добавлены visited-состояния с контролем контрастности
- Проведена глубокая очистка технического долга: удалены 6 мёртвых файлов, исправлены 14 проблем доступности (A11y)

**Безопасность и SEO:**
- Добавлен SRI (Subresource Integrity) для внешних шрифтов
- Оптимизирована JSON-LD разметка: устранено дублирование, исправлены описания для мультиязычности
- Настроен rehype-плагин для автоматической обработки внешних ссылок

Эти улучшения заложили фундамент для стабильной работы блога и подготовки к активной дистрибуции контента.

## FAQ

**Почему в блоге публикуются технические детали разработки?**
Прозрачность процесса формирует доверие. Демонстрация реальных инженерных решений ценится выше абстрактных рассуждений.

**Как можно предложить коллаборацию или указать на ошибку?**
Контакты — на странице ["О проекте"](/ru/about/). Конструктивная критика рассматривается как ресурс для развития.

**Публикуете ли вы готовые торговые стратегии для копирования?**
Мы не публикуем торговые сигналы и не даем индивидуальных инвестиционных рекомендаций. Материалы носят исключительно образовательный характер: они показывают, как формализуются правила, тестируются гипотезы и выстраивается риск-менеджмент на конкретных платформах.
